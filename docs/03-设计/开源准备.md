## 1. 开源把什么改变了

| 维度 | 之前（私人项目） | 开源后 |
|---|---|---|
| **文档读者** | 只有你自己 + AI | **陌生人**：不知道 NapCat 是什么、不知道你机器长什么样 |
| **"能跑起来"的定义** | 你能跑 = 能跑 | **陌生人在干净机器上照着 README 能跑** |
| **仓库卫生** | 别泄漏密钥就行 | **任何能定位到你本人 / 你的基础设施的信息都不该出现** |
| **代码读者** | 你（作者视角，看得懂自己的意图） | **新手**（无作者视角）+ **未来维护者** |
| **贡献者** | 无 | 同学 + 潜在路人 → 需要 PR 流程、CI、危险区保护 |
| **责任** | 自己承担 | 陌生人拿它挂自己的 QQ 号 → **要写清风险** |

> ⭐ **一句话**：私有项目的"能跑"是**作者能跑**，开源项目的"能跑"是**读者能跑**。这两件事的工作量差一个数量级。

## 2. 开源边界（**核心议题**）

> **用户要求（2026-09-22）**：「我希望 **AI 文档（即 docs 目录中的部分目录和文件）不会被开源**，但**能和我的同学共享**」

### 2.1 这条要求比"给 IP 打码"强得多

原本的阻断项（服务器 IP 裸露）**只是症状**。真正的问题是：**这套文档里有大量"只对自己有意义"的内容** —— 内部决策过程、服务器实测、AI 协作规则、踩坑记录。

打码只能解决"看得见的那一个 IP"。**把它们整体划到公开面之外，才是根治。**

| `docs/03-设计/` | AI 写的详细设计（技术 / 传输 / Agent / 本文档） | 只有你和同学 |

> 它被服务端与客户端的断言测试读取 —— 公开仓库里少了它，**别人的 `dotnet test` 直接红**。

### 2.4.1 ⚠️ 安全陷阱：**挪文件 ≠ 历史里没有**

> **公开仓库公开的是整个历史，不只是当前文件树。**
> 就算把 AI 文档整个移出去，`git log` / `git show` 里**照样查得到**那些内容 —— **包括那个生产 IP**。
>
> **已确认风险真实存在**（2026-09-22 实测）：
> ```
> git log --all -S'<server-ip-redacted>' --oneline
> → de84e75 / 34d3cdf / 1dd4ccd     ← 三个提交里都有
> ```
>
> **另一个好消息**：本仓库**从未推送过**（`git remote -v` 为空）。
> → **历史重写是安全的** —— `AGENTS.md` §六 禁的是改写**已推送**历史，这里没有已推送历史。

> ⚠️ **执行中踩到的三个坑（务必记住）**：
> 1. **`.git/info/exclude` 只管未跟踪文件** —— 先 `git mv` 会把文件放进**索引**，此时忽略规则**不命中**；必须**先 `git rm -r --cached`（必要时 `-f`）摘出索引**，忽略才生效。**顺序不能反。**
> 2. **`filter-branch --all` 之后别用 `git log --all` 做验收** —— `--all` 会把 `refs/original/*` 备份和未改写的 `origin/main` 一起算进去，**产生假阳性**。要验就验 `main`。
> 3. **原始历史里"文档被删除"那个提交会被一起过滤进来** → 过滤完 HEAD 的文件树是**空的**。必须**截断到删除之前的提交**再提平目录。
>
> 📌 `git filter-repo` 本机不可用，全程用内置 `git filter-branch`。

### 2.5 ❓ `AGENTS.md` 公开不公开？

| 选项 | 好处 | 代价 |
|---|---|---|
| **不公开**（倾向） | 它是"你和 AI 的协作约定"，属于内部工作方式；里面有你的工作流与标准 | 贡献者看不到"这个项目的 AI 政策" |
| **公开** | 透明 —— 明确声明"AI 不代写实现代码"，其实是**很好的开源形象** | 需要过一遍内容（里面提到 `docs/07-记忆/` 等私有路径）；且**公开后改动会被审视** |
| **公开一个脱敏版** | 两头好处 | 要维护两份 |

> **我的倾向**：**不公开**。理由 —— `AGENTS.md` 是**你的工作方式**，不是**项目对外的契约**。
> 如果想让贡献者知道"AI 不代写"，**在 `CONTRIBUTING.md` 里写一段就够**，不必把整份内部规则公开。

## 5. 「没什么基础的同学能参与」的工程要求

> 这一节是**给代码和文档定的门槛**，不是鼓励性口号。

### 5.1 可读性红线（**加到编码规范里**）

| 禁止 | 改为 |
|---|---|
| LINQ 炫技（三行嵌套 `SelectMany` + `GroupBy`） | 显式 `foreach`，哪怕多三行 |
| 一行塞两个嵌套三元 / 模式匹配花活 | `if` / `switch` 写清楚 |
| 缩写命名（`cfg` / `mgr` / `svc` / `tmp2`） | 全称（`config` / `manager` / `service`） |
| **无注释的"为什么"** | 反直觉处（为什么这里要加锁 / 为什么不能重试）**必须写为什么** |
| 巨型方法（> 50 行） | 拆；**一个方法一件事** |
| 隐式约定（"这里约定好大家都这么传"） | 写成 `///` 注释或断言 |

> **判据**：**同学能在不看你的情况下读懂一个文件。** 读不懂是代码的问题，不是他的问题。

## 8. 隐私自查（**每次要公开前跑一遍**）

```powershell
# ① IP / 主机名 / 内网地址
git grep -n -I -E '([0-9]{1,3}\.){3}[0-9]{1,3}' -- .

# ② 密钥形态的字符串
git grep -n -I -i -E '(api[_-]?key|token|secret|password).{0,4}[:=].{0,4}["''][^"'']{8,}' -- .

# ③ 本机绝对路径
git grep -n -I -E '[A-Z]:\\' -- .

# ④ QQ 号 / 群号（配置与文档里都不该有真实号码）
git grep -n -I -E '\b[1-9][0-9]{5,11}\b' -- .

# ⑤ 图片类（截图里常有个人信息）
git ls-files | Select-String -Pattern '\.(png|jpg|jpeg|gif)$'
```

> ⚠️ **跑之前先确认"私有面"不在扫描范围里** —— 否则会看到一堆"意料之中"的命中，反而把真正的漏点淹掉。

### 8.1 另外两项检查（**CI 里也跑，这里是手工版 = 双保险**）

```powershell
# ① 契约样例必须都是合法 JSON（改过样例后必跑）
Get-ChildItem 'docs\05-契约\*.json' | ForEach-Object {
  try { $null = Get-Content $_.FullName -Raw -Encoding UTF8 | ConvertFrom-Json; "OK  $($_.Name)" }
  catch { "❌ $($_.Name): $_" }
}

# ② Markdown 相对链接不得失效（移动 / 改名文档后必跑）
#    ⚠️ 必须【先剥掉代码块与行内代码】再扫 —— 否则文档里举例写的 ](path) 会被误报成断链。
#    老是误报的检查器，人就会开始忽略它，那它就白写了。
$root = (Get-Location).Path; $broken = @()
Get-ChildItem $root -Recurse -File -Include *.md |
  Where-Object { $_.FullName -notmatch '\\\.git\\' } | ForEach-Object {
    $f = $_
    $text = Get-Content $f.FullName -Raw -Encoding UTF8
    $text = [regex]::Replace($text, '(?s)```.*?```', '')   # 去掉围栏代码块
    $text = [regex]::Replace($text, '`[^`\r\n]*`', '')       # 去掉行内代码
    foreach ($m in [regex]::Matches($text, '\]\(([^)]+)\)')) {
      $t = $m.Groups[1].Value.Trim()
      if ($t -match '^(https?:|mailto:|#)') { continue }
      $t = ($t.Split('#')[0]) -replace '/', '\'
      if ([string]::IsNullOrWhiteSpace($t)) { continue }
      if (-not (Test-Path -LiteralPath (Join-Path $f.DirectoryName $t))) {
        $broken += $f.FullName.Replace($root + '\','') + ' -> ' + $t
      }
    }
  }
if ($broken) { '❌ 断链 ' + $broken.Count + ' 处：'; $broken } else { '✅ 0 断链' }
```

> 📌 **为什么这两项特别值得保留**：都**踩过一次** ——
> 契约样例写过真实 QQ 号；移动文档目录一次断过 11 处链接。**都是"看/想"抓不到、只有"跑"才抓得到的。**
> 它们**同时也跑在 CI 里**（`.github/workflows/ci.yml` 作业①）；这里留一份手工版，是为了
> **推之前 / 本地就能先发现**，不用等 CI 跑完再看红叉。
