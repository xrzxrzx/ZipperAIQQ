## 三、阅读顺序建议

| 你是… | 按这个顺序读 |
|---|---|
| **第一次来** | ① 本页 → ② [架构说明-新人版](02-架构/架构说明-新人版.md) → ③ [新人上手](08-上手/新人上手.md) → ④ [编码规范](04-规范/CSharp编码规范.md) |
| **要改代码** | ① [需求](01-需求/角色扮演助手-需求.md) → ② [设计文档索引](03-设计/README.md) 里找对应模块 → ③ [编码规范](04-规范/CSharp编码规范.md) |
| **想知道为什么这么设计** | ① [决策记录](07-记忆/决策记录.md) → ② [教训](07-记忆/教训.md) |
| **只想跑起来** | 直接看 [新人上手](08-上手/新人上手.md) |

> 💡 **别一开始就通读** —— `03-设计/` 有十几份，按需查比通读有效得多。

## 四、三条纪律

1. **决策一旦改变**，必须同步更新 [架构方案](02-架构/架构方案.md) + [07-记忆](07-记忆/)，**不得只在对话里说**
2. **移动 / 改名文档后必跑链接检查** —— 一次移动曾断掉 11 处链接
3. **机密永不入库** —— token / 密码 / API key 一律走环境变量或 `appsettings.Local.json`（已在 `.gitignore`）
