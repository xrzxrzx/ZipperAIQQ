## 约定

- **决策一旦改变**，先更新这里的记录，再改代码
- 每条记录带**日期**
- 只记**结论与理由**，不抄对话
- 与 [`../架构方案.md`](../02-架构/架构方案.md) 冲突时，**以架构文档为准**，并回来修正本目录

## 与全局记忆库的关系

- **项目内的事**：写本目录（首选）
- **跨项目/跨设备要用的**：同时写全局记忆库（双写）
- 全局库里已有大量本项目相关记录，位于 `projects/ZipperAIQQ/README.md`
