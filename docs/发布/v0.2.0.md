# ZipperAIQQ v0.2.0 · 语音、会话与配置全面升级

> 发布日期：2026-10-23 · 基线：`v0.1.0` → `v0.2.0`（22 次提交）
> 本次围绕 `docs/问题记录` 里的 39 条反馈，完成 **35 条**（2 条按用户要求不做/撤销），
> 并顺带修掉 4 个实现过程中暴露的隐藏缺陷。

## ✨ 亮点

- **🎙 能听语音了**：通道层接入 NapCat `fetch_ptt_text`，语音自动转写成文本再交给模型；
  首问失败会自动重试一次，连续失败熔断降级为 `[语音]`，**不阻塞消息接收**。
- **💬 会话页可读了**：会话列表显示「QQ · 昵称 / QQ群 · 群名」，支持搜索、按时间区间导出；
  消息按「时间 / 发送人 / 正文」分段着色，AI 行带樱粉色条。
- **📊 数据看得更细**：Token 卡片新增**缓存命中**数与命中率；支持**按会话**筛选；
  「各类调用」显示中文名（英文保留次行）。
- **🧩 配置页彻底重排**：拆成 **模型配置 / 运行与行为 / 人设 / 人员与名单** 四页；
  两个固定端点（`primary` + `judge`）左右并列，端点名不可改；保存幂等（无变化不写审计）。
- **🛡 工具/命令/NapCat API 三类可管理**：新增「工具管理」页，逐项配置**开关 + 最低角色**；
  低角色越界写入会被硬底线拒绝，保存即时生效。
- **📢 通知覆盖 17 类**：常用 6 类单独分组，其余 11 类可搜索；加好友/加群请求**只记录、不自动通过**。
- **🧠 系统提示词可编辑**：与人设分开存储，内置默认值可一键恢复；
  默认规则明确「工具失败要如实说、权限不足就说权限不足、回忆用『我想起来了』而不是『查到了』」。

## 🆕 新增

- **语音**：`RecordSegment`、`ISpeechTranscriber`、NapCat 语音转写与失败重试/熔断。
- **会话**：昵称解析（5 分钟缓存，失败回落编号）、会话搜索、时间区间导出、消息分段高亮。
- **数据**：`CallMetrics.CachedInputTokens`、会话维度聚合、类别中文名。
- **配置**：三页拆分、保存幂等、端点名固定、可搜索下拉（`FilterableComboBox`）、多选列表（`MultiSelectList`）、
  每卡就地状态提示、人设启用开关（`SessionPersonas.Enabled`）。
- **策略**：`IExecutionPolicy` + 工具/命令/NapCat API 目录，60 秒刷新 + 保存即时重载。
- **通知**：`NoticeType` 扩到 21 类，`request` 大类接入；`getBehavior` 返回分组。
- **运维**：服务端日志检索（时间/级别/关键词，等级高亮）、AI 按时间检索记忆（`search_history` 时间参数 +
  `get_history_between`）、网页搜索工具（实验）、重启服务端入口与守护脚本 `scripts/run-server.ps1`。
- **架构**：删除 994 行的 `MainViewModel`，拆为 `ShellViewModel` / `StatusViewModel` / `AuditViewModel`
  + 各页独立 VM；新增系统提示词注入（每轮与重注入 system 一起）。

## 🐛 修复

- **自己入群会触发群成员变更响应**：自激过滤从消息扩展到通知，`group_increase/decrease` 补 `target_id` 回落。
- **超级表情读不出**：未知 `face id` 不再统一显示 `[表情:未知]`，改为带 id（便于复读与排查）。
- **黑白名单不能并存**：改为双名单 + 同条目互斥 + 黑名单优先；主人私聊与主人所在群自动放行。
- **拉黑管理员无校验**：返回 `409` 并列出冲突账号，确认后剥夺管理员并写审计。
- **管理员重启后丢失**：启动时从库加载 `access.admins` 到权限解析器。
- **端点读取恒为 judge**：按 `roles["Chat"]` 选择端点；端点名改为固定白名单，拒绝改名/新建。
- **保存无幂等**：`setConfig` / `setSettings` / `setAccess` / `setPersona` 全等时跳过写库与审计。
- **审计页不自动滚到底**：集合改「旧 → 新」，刷新后自动定位最新一条。
- **日志查询 500**：Serilog 持有日志文件时改用 `FileShare.ReadWrite` 共享读。
- **策略层启动死锁**：策略构造期不再通过 DI 取命令列表，改用静态 `CommandCatalog`。
- **配置页布局混乱 / 长文本撑宽 / 保存提示只在页底 / 下拉只能用一次**：统一卡片布局、文本换行、
  就地状态、下拉聚焦恢复候选。

## 🔧 变更与升级注意

- **数据库自动迁移**：schema `v10/v11 → v12`（只增列），旧库启动即升级；**升级前仍建议备份 `data/`**。
- **导航结构调整**：概览（状态 / 数据 / 审计 / 服务端日志）、对话（会话）、配置（模型配置 / 运行与行为 /
  人设 / 人员与名单 / 工具管理），展开状态会记住。
- **重启服务端**只负责优雅停止，重新拉起需要守护脚本：
  `scripts/run-server.ps1`（退出码 0 时自动重启）。
- **网页搜索**复用 LLM 端点 key，`ZIPPER_SEARCH_BASEURL` 可覆盖地址；上游调用形态尚待实测，
  不可用时工具会如实返回「搜索服务不可用」，不会编造结果。
- **客户端 / 服务端需同时更新**：新增 action（`getToolCatalog`、`setToolPolicy`、`queryLogs`、
  `restartServer`、`getSystemPrompt` 等）旧服务端不提供。

## ⚠️ 已知限制

- 语音转写依赖 NapCat 的 `fetch_ptt_text`；不可用时降级为 `[语音]` 占位。
- 表情目录仍是 116 项（最大 id 326），超大表情只能显示 id，**未编造名称**。
- 网页搜索为实验特性，调用形态待实测。
- #21（AI 自主拉黑）按用户要求暂缓；#33（日志保留配置）用户已撤销。
