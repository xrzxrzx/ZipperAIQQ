# ZipperAIQQ v0.6.0 · 可靠性与会话交互

> 发布日期：2026-11-06 · 基线：`v0.5.2` → `v0.6.0`
> 需求：[运行可靠性与会话交互](../01-需求/运行可靠性与会话交互-需求.md) · 设计：[轮次机制](../03-设计/轮次机制设计.md)

这一版的主线是**让机器人在坏条件下也不掉链子，同时把「怎么回、回多长、什么时候回」交还给人设 agent**。
可靠性（通道/额度/告警）、会话交互（名单/留档/长度/轮次）、跨平台与记忆召回四条线一起收口。

---

## ✨ 新增

### 通道可靠性
- 共用重连底座：指数退避 + 抖动、连续失败熔断、冷却后半开重试
- 通道看门狗：断开自动重拨，`/status` 显示连通/熔断与连续失败数、断开时长
- 熔断时**非关键轮次直接短路**（邮件汇总/压缩/漂移重试不再白烧 token），记 `agent.shortcircuit`

### 额度与花费（DeepSeek）
- 余额常驻采样（10 分钟）+ 花费推算（余额差值，含充值补偿）
- 额度闸门：默认关、日窗口、上限 ¥5、预警 0.7；`getQuota/setQuota` 热更新
- 数据页「额度闸门」卡 + `/status` 花费三行（余额/花费/剩余）

### 告警
- 按平台降级投递：QQ → 抖音 → 库 + 客户端事件；成功即停、只对成功去重
- 主人反馈发送失败改走告警链；数据页「最近告警」实时刷新

### 定时任务
- 到点**投给目标会话的 agent**（不再直接发通道）：可改写、可沉默、超时 60s 兜底原内容
- 执行审计 `ScheduleExecutions`（已发送 / 决定不发 / 超时兜底 / 失败）+ 客户端「定时任务执行」卡
- 执行期间禁止创建新任务（防套娃）；失败 10 次封顶并告警

### 名单与留档
- 名单改为**一份名单 + 显式模式**（白/黑），空名单语义写死；旧双名单按并集自动推导
- 管理员拉黑仍要 409 二次确认（确认后剥夺管理员）
- **消息一律入库**：被拦消息留档、不回复不执行命令，但**对模型可见、可检索**；会话页标「留档（未处理）」/「未回复」

### 跨平台
- 主人账号一次给全（qq / douyin 并列注入上下文）
- 跨平台通讯录 `query_contacts`（带平台标签、单平台失败隔离、默认管理员）
- 平台接入页显示「各平台主人」；统一身份表成为主人主数据（settings 降为兼容镜像）

### 回复长度（R-11）
- 场景预算：群聊插话=短（120 字/2 条）、私聊=正常（600/5）、「详细说说」=长（1500/8）
- 超预算先让模型重写，仍超长按句末裁剪；`reply.trimmed` 指标；`reply.length.enabled=false` 可回退

### 轮次机制（R-04 / R-10）
- 同一会话**永不并行两轮**；一轮可挂起等待下一条消息，3 分钟无消息静默收轮
- 私聊运行中消息**steer 注入**当前轮（工具调用完成后、下一次模型调用前）
- 群聊由 JEV **同一次调用**回答「要不要回 / 引导还是排队」；连续引导上限 2
- `TurnLogs` 审计 + `getTurnLogs`；指标 turn.duration / suspended / steer / followup / interrupted / jev.judge

### 记忆
- 跨会话向量召回 `recall_related`：0.7 相似度 + 0.2 关键词 + 0.1 新鲜度，结果带来源会话与相关度
- 图（MemoryNodes/Edges）**评估后暂缓**：实测 63% 邻居同会话，真正缺口是跨会话召回

## 🐛 修复

- **重连后两条接收循环并发读同一 socket**：大帧被撕半，JSON 解析失败，`/status` 等入站消息被吞
- **部署启动失败的 DI 漏注册**：`QuotaOptions` / `ChannelReliabilityOptions` / `AlertOptions`；新增 `ServiceGraphTests`（ValidateOnBuild）
- 通道不可用时邮件汇总仍空转重试（1s/2s/4s），改为立即交回指数冷却
- NapCat `StartAsync` 重复建连（Program 与看门狗撞车）
- 定时任务失败无上限刷屏（新增 10 次封顶 + 告警）
- 服务重启后看门狗不识别「已恢复」，健康状态卡在断开

## ⚠️ 行为变化

| 变化 | 影响 |
|---|---|
| 名单改为单份 + 模式 | 旧白/黑双名单会自动取并集；管理员拉黑需确认 |
| 消息一律入库 | 名单外内容现在会**留在本地**并对模型可见（可检索）；如介意请清库 |
| 定时任务投 Agent | 每条任务到点会多一次模型调用（拍板接受） |
| 回复长度预算默认开 | 超长会被重写/裁剪；`reply.length.enabled=false` 可关 |
| 轮次挂起 3 分钟 | 期间新消息可能注入当前轮；不再「一有消息就收轮」 |

- 图记忆暂缓；客户端未逐页真机点验
