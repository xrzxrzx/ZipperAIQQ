# ZipperAIQQ v0.4.0 · 图片、定时、主人反馈与外部接口

> 发布日期：2026-10-25 · 基线：`v0.3.0` → `v0.4.0`

## ✨ 新增

- **消息时间带日期**：会话页从 `HH:mm:ss` 改为 `MM-dd HH:mm:ss`，跨天历史不再分不清。
- **图片 / 表情包真正可读**
  - 收到当前消息时**立即下载**图片字节（8s / 8MB 上限，30 分钟内存缓存）。
  - 按魔数识别真实 MIME（JPEG / PNG / GIF / WEBP），不再一律按 `image/jpeg`。
  - **GIF / WebP 取首帧转 PNG**（SkiaSharp），动图也能被模型看到。
  - 链接过期 / 下载失败时用占位文本，不阻塞其他消息。
- **定时任务可发给别人**：`schedule_create` 增加 `target`（`qq:p*` / `qq:g*`），默认当前会话；指定别人需要管理员/主人。
- **主人反馈**
  - 可勾选「撤回消息（带原文）」与「外部接口消息」。
  - 撤回会按消息 ID 查回原消息内容；查不到就明确说「原文不可得」。
  - 目标默认主人私聊，也可指定会话；主人自己撤回不会转发。
- **外部应用 WebSocket 接口**
  - 反向：外部连入 `/ws/ext`，支持多个监听块（名称 / 启用 / IP 手填 / 端口 / 独立 token）。
  - 正向：服务端主动连出，支持多个目标；保存后立即重连。
  - 客户端「外部接口」页：Pivot 分页（全部 / 反向监听 / 正向连接）、自动换行卡片、独立新建与编辑对话框。
- **网页搜索独立配置**：模型配置页新增「网页搜索」卡，使用**自己的 BaseUrl 与加密 API Key**，与对话模型完全解耦。

## 🐛 修复

- **表情包读不到**：链接 `rkey` 过期 + MIME 误判（`.jpg` 实际是 GIF）两个原因都已处理。
- **图片下载失败伪装成正常**：失败会明确占位并记日志，不再静默当成空消息。
- **CI 守卫误报**：测试里的真实 QQ 号换成占位号；日志时间范围与文件日期改为按本机时区解析（UTC runner 上不再错位）。
- **外部接口编辑框主题不一致**：统一深色主题与应用按钮样式。
