# ZipperAIQQ v0.3.0 · 网页搜索、主人优先与通知语义

> 发布日期：2026-10-25 · 基线：`v0.2.1` → `v0.3.0`

## ✨ 新增

- **网页搜索对齐官方 API**
  - Search：`POST /v1/tools/search`，使用 `count` / `need_content`（不再请求错误的 `/search`）。
  - Fetch：`POST /v1/tools/fetch` 官方优先，失败自动回落自建抓取。
  - 新增 `search.enabled` / `search.baseUrl` 配置（环境变量 + `server.yaml`）。
  - 搜索结果带标题 / URL / 摘要，模型可直接引用来源。
- **主人优先**
  - 提示词改为三层优先级：系统安全与工具权限 > 主人的要求 > 普通人约束。
  - 主人要求改称呼、改设定、换语气、扮演别人时**照做**；非主人仍被身份约束。
  - 默认系统提示词新增「主人优先」小节，可编辑、可重置。
- **自我身份**
  - 通道发现 `self_id` 后写入 `bot.selfId`，重启自动恢复。
  - 每轮向模型注入「你自己是谁（QQ 号）」，避免把别人的互动当成冲自己来的。
  - 新增只读诊断 `getSelfInfo`：通道 / 配置 / 持久化 / 生效四个值一眼对照。
- **戳一戳语义**
  - 别人戳别人：**正常响应**，正文明确标注「不是你，别当成戳自己」。
  - 别人戳机器人：正文「A 戳了你」。
  - 只有自己触发的操作 / 自己被拉入退出群才丢弃。

## 🐛 修复

- **网页搜索一直 404**：端点少了两级路径（`/search` → `/v1/tools/search`），参数 `top_k` 也不是官方字段。
- **搜索失败被伪装成「没搜到」**：非 2xx / 解析失败现在抛错，工具如实回「搜索失败（HTTP xxx）」；只有 200 空结果才是「没搜到」。
- **`fetch_url` 没走官方接口**：原来自建 GET + 正则，现改为官方 fetch 优先、自建回落。
- **戳 AI 没反应**：上一版把所有 `Target == self` 的通知在通道层丢弃，连戳机器人都被吞；现在只丢自己触发的与被拉入/退出群。
- **自己入群被当成别人入群**：自激过滤改为按「谁触发 / 是否是自己入退群」判定，不再误判。
- **日志检索在 UTC 机器上错位**：文件日期与时间范围改为按本机时区解析（CI 上暴露）。
- **搜索空结果与失败同形**：模型与用户现在能区分「搜不到」和「搜索坏了」。
